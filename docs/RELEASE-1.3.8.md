- 设置新增「划词后自动翻译」，开启后完成划词直接显示翻译结果，关闭后恢复「翻译 / 问 AI」按钮。

## 安装

本次提供源码包 `huaci-mac-1.3.8.zip`。先退出旧版，解压到独立目录，在 macOS 13+ 上运行 `bash Build.command`，完成检查后将生成的 DMG 中的 Huaci 拖到「应用程序」。支持 Apple Silicon 和 Intel Mac，构建结果使用当前 Mac 的架构。现有 API、目标语言和其他设置会沿用。

安装后打开设置，勾选「划词后自动翻译」。如需使用「问 AI」，可取消该勾选以恢复浮动按钮，或从菜单栏打开 AI 对话。

本版版本号 1.3.8，构建号 23。已完成源码复核、Shell 检查及打包校验；当前环境没有 Swift 编译器或 macOS SDK，尚未执行原生编译、Swift 回归检查或界面实测，未生成新的 DMG。Mac 构建入口会先运行完整类型检查和本地回归检查，不使用真实 API 密钥。
