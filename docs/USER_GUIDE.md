# 使用说明

适用于划词助手 1.3.7。返回 [项目首页](../README.md) · 查看 [更新日志](../CHANGELOG.md)。

## 安装或升级

Apple Silicon（M 系列）Mac 可从 [Releases 发布页](https://github.com/foreverdzx/Huaci-Mac/releases) 下载 `Huaci-Installer-arm64-v1.3.7.dmg`，双击打开并将 Huaci 拖到「应用程序」，再配置 API 与辅助功能权限。安装或替换前先退出正在运行的旧版。本次 DMG 仅含 ARM64 应用，需要 macOS 13 或更高版本。

源码包包含完整 Swift 源码与构建脚本，适合 Intel Mac 或希望自行构建的用户；脚本生成适合当前 Mac 架构的应用。以下步骤用于从源码安装或升级：

1. 升级时先从菜单栏或设置底部退出旧版划词助手；已隐藏菜单栏图标时，重新双击 Huaci.app 打开设置。
2. 将完整源码包解压到独立文件夹。GitHub 自动生成的源码包可能带分支名或版本号，若要使用下一步的示例命令，可将解压目录改名为 `Huaci-Mac` 并放到「下载」目录。若旧源码文件夹仍在，先改名保留，不要合并覆盖。
3. 打开「终端」，运行 `bash "$HOME/Downloads/Huaci-Mac/Build.command"`。脚本先运行本地回归检查，再编译应用。也可输入 `/bin/bash `（末尾一个空格），把解压后的 `Build.command` 拖入终端，按回车；这不依赖文件的执行位。
4. 若提示缺少 Apple Command Line Tools，在终端运行 `xcode-select --install`，安装完成后重试。无需完整 Xcode 或第三方依赖。
5. 构建完成后，自动打开 `dist/Huaci-Installer.dmg` 的安装窗口。将左侧 Huaci 拖到右侧「应用程序」；升级时替换原路径中的应用。复制完成后，从「应用程序」打开 Huaci，并推出安装磁盘。若窗口没有自动打开，可双击该 DMG；若制作 DMG 失败，则手动安装保留的 `dist/Huaci.app`。
6. 在设置中填写接口、密钥、模型，保存并测试。旧版配置和钥匙串密钥会沿用。
7. 在「系统设置 → 隐私与安全性 → 辅助功能」中允许 **Huaci / 划词助手**。若列表中没有，用 `+` 添加实际安装的应用。

成功后按回车可尝试关闭本次构建的 Terminal 窗口；若系统询问 Terminal 自动化控制，需要允许才能自动关闭。窗口存在其他标签页或任务、使用其他终端、权限未允许或系统未完成关闭时，按 ⌘W 关闭当前标签页即可。脚本不会退出整个 Terminal，也不更改「Shell 退出时」的全局或配置描述文件设置。

应用默认显示菜单栏图标，不显示 Dock 图标。菜单栏可打开设置、AI 对话、暂停划词或退出。可在设置中隐藏菜单栏图标；隐藏期间保持划词开启，重新双击应用可打开设置并恢复图标或退出。

脚本双击无法执行时，在终端输入 `bash `（末尾一个空格），拖入 `Build.command`，按回车。错误会保留在终端中。

本地构建使用临时签名，没有开发者证书或 Apple 公证。重新构建后，系统可能再次要求钥匙串访问或辅助功能授权；必要时在辅助功能列表中移除旧条目，添加新应用。不要同时打开不同路径的多个副本。

构建脚本发现 Huaci 仍在运行时会停止，避免替换正在使用的应用。如果你已有专用代码签名证书，可以设置 `HUACI_SIGNING_IDENTITY` 后运行 `Build.command`，持续使用同一身份；脚本不会自动创建证书、修改钥匙串信任或在签名失败后退回临时签名。默认临时签名的后续更新仍可能需要重新授权。

## DeepSeek 配置

| 字段 | 填写内容 |
| --- | --- |
| API 地址 | `https://api.deepseek.com` |
| API Key | 你的 DeepSeek 密钥，仅在应用设置中填写 |
| 模型名称 | 服务商当前提供的模型 ID |

填写 API 模型 ID，而不是产品展示名称；可用模型以你的账户与 [DeepSeek 官方文档](https://api-docs.deepseek.com/) 为准。应用不会锁定某个模型。

DeepSeek 官方裸地址会规范为 `https://api.deepseek.com/chat/completions`，也可填写完整端点或 `https://api.deepseek.com/v1`。对官方域名的请求会按 [思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/) 发送 `thinking: {"type": "disabled"}`，用于直接返回翻译或问答正文。

结构化单词查询另按 [DeepSeek JSON Output 文档](https://api-docs.deepseek.com/guides/json_mode/) 设置 `response_format: {"type": "json_object"}` 与 `max_tokens: 4096`，并在本机校验词典字段。其他兼容服务使用同一 JSON 提示词，但不发送这些可选参数；其模型也需要能遵循指定结构。

也支持其他 **OpenAI 兼容 Chat Completions** 服务：填写其 HTTPS 基础地址、密钥和模型 ID。其他裸主机地址补全 `/v1/chat/completions`；已有版本路径则追加 `/chat/completions`；完整端点不重复追加。DeepSeek 特有参数不会发送给其他域名。

本机服务可用 `http://localhost:端口/v1`，无须认证时可留空密钥；本地网络访问仍受 macOS 策略约束。不支持原生 Anthropic Messages、Gemini generateContent、仅有 Responses 接口，以及需要查询参数或额外认证头的服务。连接测试会发送简短请求，可能消耗少量额度。

余额区位于 API 配置下方。DeepSeek 官方地址可显示真实余额，OpenAI 官方地址提供账单入口；其他兼容接口和中转站的余额需要单独适配。余额查询仅使用已保存的配置，编辑后先保存；点击「刷新余额」不会重新保存设置或触发聊天连接测试。

## 翻译与连续提问

**翻译**

选中文字后点击「翻译」，结果浮窗顶部显示「源语言：自动识别」和目标语言下拉框。先在本机判断能否确认同语言并跳过；需要请求时再由模型判断源语言，无须手选。普通译文较短时使用较大字号，内容增加后逐步缩小，最小为原有的 14 pt；窗口高度随内容调整，长内容达到屏幕上限后滚动查看。滚动查看前文时不会强制拉回底部。切换目标会取消当前任务，并重新判断同一段选中文字是否需要翻译。选择会保存在本机，下次继续使用。

原文与目标语言相同时无需翻译，单词也不展开词典；本机能确认时直接保留原文并提示，无接口调用。本机无法确认时仍可能请求模型，模型也被要求只提示无需翻译。需要跨语言处理时，单个自然语言词语按词典形式解释，多词短语和句子直接翻译。产品名、版本号、代码等可保留原样；陌生名称不会硬凑词义。如果接口返回与原文完全相同的内容，界面会明确提示。

英语单词词典的音标旁可点击小喇叭朗读；默认美音，设置中可选英音。模型返回的源语言用于判断是否显示按钮，发音始终使用本次选中的原词，目标语言不改变发音语言。音标无法确认时仍可尝试系统朗读。当前发音入口只用于英语单词词典，普通句子和「无需翻译」结果不显示此按钮。

**问 AI**

输入区上方的「解释这段」「提炼要点」「润色表达」三个按钮始终展开，点击即发送。优先使用输入框中的内容，输入框为空则使用本次划词；没有可用文本时提示补充，不发送请求。回答生成期间预设按钮暂不可用。

点击「问 AI」后，对话窗口会移动到本次选区附近，当前选中文字在新会话中立即作为问题发送，并显示回答。后续问题自行输入并点击「发送」或按 **⌘Return**，普通 Return 换行；连续追问和回答更新不会移动窗口。追问的接口请求只带上本次会话中已完成的问答；上一段划词会话不会带入。如果只是从菜单栏打开「AI 对话」，则在原有位置显示当前会话，等待你输入并发送问题。

切换到其他应用时，对话窗口和内容保留。关闭窗口会停止正在生成的回答；从菜单栏重新打开可继续查看当前会话。下一次划词并点击「问 AI」会以新会话直接提交选中文字，替换旧记录；若旧回答还未完成，则停止它。接口配置或输入校验不通过时，不会中断原请求或清除旧记录，所选文字放入输入框供编辑后重新发送。

「清除记录」停止当前回答并清除本次已发送问答，尚未发送的草稿保留。需要保留对话时点击「导出记录」，在系统保存窗口中选择 `.md` 文件的名称和位置；导出的文件是点击按钮时的内容快照，之后收到的新回答不会追加到已导出文件。退出应用会清空内存会话，已导出的文件保留。

失败或停止的回答保留已收到的文字，并标记未完成；它们不会进入后续请求的上下文。重试会重新请求这一轮，不重复添加用户问题。不自动重发失败请求。

每个问题或选区最多 20,000 个字符，一次请求文本总量最多 100,000 个字符，超过时提示缩短内容或清除记录；服务商可能另有更低限制。

## 全局取词

应用通过 macOS 辅助功能读取选区，兼容程度取决于原应用是否提供文字和选区接口。

- 自动取词始终随「启用划词助手」工作，不受复制兼容模式开关影响。
- 拖动、双击或使用 Shift + 方向键选词，可触发浮动按钮。
- 手动读取选区：**Control + Option + 空格**，或菜单栏「读取当前选区」。
- 无法自动取词时：在设置中开启 **「复制后显示划词选项（兼容模式）」**，选中文字后按 **⌘C**。
- 备用入口：复制文字后，选菜单栏「使用剪贴板文字」。此入口不依赖辅助功能授权。
- 未固定的翻译浮窗会在点击其他应用或滚动原页面时关闭，同时取消翻译。图钉固定后保留窗口和当前选词；× 或 Esc 可主动关闭。独立 AI 对话不受这些操作影响。

部分 Chrome / Electron 应用首次启用辅助功能树需要短暂等待；代码会在原选区仍有效时重试读取一次。密码框不自动取词。图片、扫描 PDF、画布、部分终端或自定义编辑器可能无法读取；本版没有 OCR。

兼容模式需要辅助功能权限以接收其他应用中的 ⌘C。只在按下相关快捷键时记录剪贴板变更计数，在明确按下 ⌘C 后短暂等待新文字，不持续读取剪贴板内容。没有变化、复制的是图片/文件、应用标记为隐藏内容或你已切换应用时，不弹出选项；不会把没有变化的旧剪贴板当成新选区。复制很慢、事件通知延迟等情况下仍可能漏触发，可使用菜单栏备用入口。

剪贴板文字只在上述兼容操作或你点击菜单栏「使用剪贴板文字」时读取，不模拟复制按键，也不改写剪贴板；「复制结果」按钮会按你的指令写入结果。

## 模型信息与排错

结果区显示配置的模型、接口返回的模型标识（若提供）和接口域名。这里读取的是响应元数据；模型在正文里对自身名称或知识截止日期的描述不能用于核实调用身份。

如果显示「已完成」，但回答类似「我不了解这个模型」，说明收到的是模型正文，这不等于连接失败。新版提示默认中文，并要求区分已知信息和不确定内容，但无法保证模型对最新产品的知识准确。可在对话中补充资料并继续追问。

遇到 401 / 403 / 404 / 429 或连接失败，请在设置中测试，并检查密钥、权限、地址、模型 ID、额度及网络。接口错误会显示为错误信息，不会用原文冒充翻译结果。

已授权但没有浮窗时，可先退出重开，再用普通文本编辑器测试；也可使用全局快捷键或剪贴板入口。快捷键被其他程序占用时，菜单会提示，其他入口仍可使用。

辅助功能只影响跨应用读取选区；即使尚未授权，菜单栏「使用剪贴板文字」、AI 对话以及设置中的 API 测试仍可用。

## 数据处理

- 密钥保存在 macOS 钥匙串；接口、模型、目标语言、英文发音口音、启用状态、菜单栏图标与兼容模式开关保存在本机偏好设置。
- 读取选区、复制后弹出选项或打开空白对话不发送网络请求。本机确认同语言时跳过翻译请求；其他翻译、问 AI、发送后续问题、重试或测试连接时请求配置的服务。
- 翻译发送所选文字和翻译指令；问答发送系统指令、当前问题及本次会话已完成的问答。不会附带网页地址、窗口标题或其他应用文字。
- 当前 AI 对话及其回答只留在进程内存，退出后清空；点击「导出记录」并确认保存后，写入你选择的 Markdown 文件。翻译缓存同样只在内存中保留。
- 翻译历史默认自动保存到 `~/Library/Application Support/Huaci/translation-history.json`，包含原文、译文、目标语言、时间和模型名称，不含 API Key。设置中可关闭自动历史或清空历史；清空历史保留收藏，收藏可单独删除。没有中转服务器、统计服务或自动云同步。
- 内容只按文字展示，不执行模型返回的 HTML 或命令。服务商的数据处理方式由其政策决定。
- 停止或关闭会取消本机连接，但服务商可能已经生成并计费。
- 点击小喇叭使用已安装的系统语音，不调用翻译接口或额外的云端语音服务。用户在系统设置中下载缺少的语音时需要联网。
- 打开设置、保存配置或手动刷新时，已配置的 DeepSeek 官方账户会用原 API Key 查询余额。余额请求只访问官方余额接口、不跟随重定向，不发送选区或聊天记录。余额和更新时间不写入本机偏好或导出的对话文件。OpenAI／未适配服务不自动发送余额查询请求。

## 验证状态与源码

交付环境没有 macOS SDK 或 Swift 编译器。本版已完成源码检查、Shell 脚本语法检查及 plist 校验，**尚未在 Mac 上编译或进行实际界面测试，也未使用真实密钥测试接口**。

`Build.command` 会先调用 `Test.command`，在你的 Mac 上编译并运行回归检查，再构建及验证应用签名。这些检查覆盖请求地址、目标语言、DeepSeek 参数、会话上下文、停止与重试、旧配置迁移、兼容模式默认关闭与持久化，以及 UTF-16 选区、表情字符、多选区和越界拒绝。1.1.5 新增可注入取词源的回归检查，覆盖有效焦点选区不受坏扩展控件阻断、可选属性缺失、父控件选区、密码框、循环和预算耗尽；这些模拟检查不读取其他应用。不发送网络请求、不读取钥匙串。在此交付环境中，它们没有被执行。

首次运行请检查：`apple` 返回词典式解释；`I like apples.` 只返回译文；短译文窗口收缩、长内容逐渐展开并滚动；切换日语后解释与译文使用日语；点击「问 AI」立即提交选中文字，后续问题可手动发送；停止后不继续刷新；切换应用后对话仍保留。新增的窗口尺寸变化与即时提问仍需在 Mac 上实测，模型分类与输出质量尚未用真实 API 验证。

1.1.6 新增通过注入识别结果验证同语言判断的策略检查，以及菜单栏显示与启用状态的迁移、归一化和保存检查；它们不访问真实偏好设置、不依赖语言模型的概率恰好取某个值。Mac 实测需确认：目标中文时中文句子提示无需翻译；英语目标下英语单词不展开词典；中文夹英文以及需要简繁转换的文字不会直接跳过；隐藏图标后自动划词继续、停用选项禁用、重新双击应用可打开设置、恢复图标后可暂停。**新增检查尚未在交付环境运行，系统语言模型的识别效果与菜单栏操作尚未实测。**

1.1.7 更新会话回归检查：新划词隔离旧记录、无效问题保留原会话、窗口内追问正常、清除后状态不被迟到更新恢复；新增 Markdown 格式检查：全部轮次顺序、生成中/停止/失败状态、中文与表情、原始代码围栏、导出快照不改变会话。Mac 实测需检查保存/取消/覆盖/写入失败，以及生成中导出和清除行为。**这些 Swift 检查与原生保存窗口尚未在交付环境运行。**
